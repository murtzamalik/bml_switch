Prerequisites
-------------
  Docker Engine + Compose, git, reachability to 10.2.60.66:7005, port 18080 free

Steps
-----
  git clone <this-repo-url>
  cd bml_switch
  cp .env.example .env
  docker compose -p bml_switch -f docker-compose.server.yml up -d --build

Health
------

  Expect: "mockImal": false
